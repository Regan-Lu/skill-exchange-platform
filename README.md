# SkillSwap 技能互换局 · 技能互换平台

> 你的技能，就是硬通货。想学啥？拿技能换。

## 🔗 在线访问

**https://regan-lu.github.io/skill-exchange-platform/**

无需安装，打开即用。数据保存在浏览器本地（localStorage），刷新不丢失。

## 📖 项目介绍

很多人想学习新技能（吉他、摄影、Python……），却因为价格、自制力等原因难以坚持；而对自己擅长的技能，又缺少分享和变现渠道。

**SkillSwap 技能互换局**是一个技能互换社区原型：你会的教别人，你想学的找人换——免费、互相督促、还能认识同频的搭子。

### 核心功能

| 模块 | 说明 |
| --- | --- |
| 💛 我能教的 / 💜 我想学的 | 首页双入口，挂上技能或找到想学的技能 |
| 🗂 技能索引 | 8 大分类（乐器 / 体育 / 编程 / 语言 / 摄影 / 设计 / 生活 / 艺术），点进去还有二级细分 |
| 🛒 技能广场 | 按 📍 距离（1km/3km/5km）、💰 价格（仅交换/200以下/200-500/500-1000/1000+）、⏰ 时间（1h内/3h内/自定义时段）三维筛选，支持综合/距离/价格/时间排序与关键词搜索 |
| 🧲 智能匹配 | 基于技能名片双向配对：🔄 完美互换 → 📚 可以约学 → 🎓 可以约教，附匹配理由 |
| 🤝 交换中心 | 发起交换请求、接受/婉拒邀约、成交记录管理 |
| 🃏 技能名片 | 新手引导生成个人名片，随时可编辑 |

### 技术说明

- 单文件 HTML 原型（`index.html`），零依赖、零构建，双击即可本地运行
- 预置 12 位虚拟技能主理人数据，localStorage 持久化个人发布与交换记录
- 活力潮流风视觉：撞色 + 粗描边卡片 + 硬阴影
- 通过 GitHub Pages 部署，`main` 分支推送后自动更新线上版本

## 🚀 本地运行

```bash
# 直接双击 index.html，或：
open index.html
```

## 📝 更新发布

```bash
git add -A && git commit -m "更新说明" && git push

```
